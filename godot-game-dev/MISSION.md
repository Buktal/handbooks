# Mission: Game Dev（Godot 2D 独立游戏开发）

## Why
用户是经验丰富的后端/前端开发者、游戏纯小白，想从零做出第一款能上架 TapTap 赚广告钱的 2D 单机游戏（Godot + 试玩版 + 激励视频路线）。

## Success looks like
- 独立完成一个完整可玩的 2D 小游戏：输入、碰撞、UI、音效、游戏状态、打包发布（手册第 5、6 章实战《接金币》）
- 走完手册第 10 章的七阶段路线图：定方向 → 纸面原型 → 最小原型 → 垂直切片 → 内容量化 → Juice 打磨 → 接入合规 → 上架运营
- 游戏以 TapTap 试玩版形式上架，接入激励视频并跑通变现（人均 3~5 次/日的合规点位设计）
- 时间预期：全职约 2~3 个月做出并上架第一款（业余时间约翻倍）

## Constraints
- 技术栈：Godot 4.x 标准版 + GDScript（不用 .NET/C# 版，不碰引擎源码）
- 选品约束：2D 单机、一句话说清、30 秒一局、失败立刻重开、内容靠数值扩展而非新机制
- 变现路线：TapTap 试玩版 + 激励视频（IAA），不开启 IAP，合规零负担优先
- 教学语言中文；游戏术语首次出现配白话解释并对照 Web/后端概念
- 依赖外部知识库：`taptap`（上架/合规/变现）、`game-publishing-cn`（渠道对比），位于 `D:\Ideas\docs`

## Out of scope
- 3D 与联网多人
- IAP 内购与买量投放
- 引擎源码编译 / 自制引擎
- 原创玩法（第一款的目标是完整复刻一个已验证好玩的品类）
